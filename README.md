# .github

The organisation's public face on GitHub. Two things live here, and GitHub
reads both from this repository because it is public and named `.github`:

| Path | Where it shows |
|---|---|
| `profile/README.md` | the landing at [github.com/Campfire-Red](https://github.com/Campfire-Red) |
| `SECURITY.md` | the security policy of every org repository that has none of its own |

`profile/icon.svg` is the app icon, a copy of Campfire's
`app/src-tauri/icons/icon.svg`.
